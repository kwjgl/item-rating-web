# 평정용 12문항 설계

최종 준거(4준거 14지표)에 맞춘 평정용 디지털 평가 문항이다.
공통 단서: 모든 지표는 해당 문항이 측정하려는 능력과 응시 학습자에 비추어 판단한다.

- 결함 문항 8개: 준거별 2개, 서로 다른 지표 8개. 한 문항에는 대상 지표 하나의 결함만 넣는다.
- 결함 없는 문항 4개: 14개 지표를 모두 충족한다.
- 결함 사례는 준거표의 결함 예시와 원리는 같고 사례는 다르다.

## 보는 법

| 주소 | 내용 |
|---|---|
| `items/index.html` | 설정 파일대로(결함 8개 켜짐) |
| `items/index.html?clean=1` | 결함을 모두 끈 판 |
| `items/index.html?item=5` | 5번부터 |
| `items/index.html?panel=1` | 문항 화면 밖에 연구자 설정 칸(결함 켜고 끄기, 대상 지표) |
| `items/index.html?off=bigMascot` / `?on=…` | 그 결함만 끄기/켜기(쉼표로 여러 개) |

결함 기본값과 지표 이름은 `items/config.js` 한 곳에 있다. 델파이 조사 뒤 준거가 바뀌면 그 파일의
`indicators`(지표)와 `defects`(결함 스위치)만 고치면 된다. 문항 내용은 `items/items.js`에 있다.

## 화면 구성

- 1280×800 고정 캔버스(11인치 태블릿)를 창에 맞춰 통째로 확대·축소한다. 모든 평정자가 같은 배치를 본다.
- **플랫폼 공통 요소(평정 대상 아님):** 위쪽 짙은 띠(교과·문항 번호·연습장), 오른쪽 회색 칸(문항 번호, 정답 확인).
- **평정 대상 영역:** 가운데 흰 칸(`.p-main`) 하나.
- 조작(고르기·입력·끌기·잇기)은 모든 문항에서 같은 코드로 정상 동작한다.
  - 끌기와 '누르고 칸 누르기'를 모두 지원하고, 놓은 카드는 다시 옮길 수 있다.
  - 선을 누르면 지워진다.
  - 되돌리기·반응 속도 같은 플랫폼 기능 수준의 결함은 없다.
- 모든 문항은 결함을 켠 판과 끈 판 모두 스크롤 없이 한 화면에 들어온다(자동 점검).

## 대상 지표

| 준거 | 결함을 넣은 지표 | 쓰지 않은 지표(12문항 모두 충족) |
|---|---|---|
| 화면 요소의 필요성 | 정보 선별, 장식 절제 | 반복 최소화 |
| 화면 정보의 명료성 | 색 외 구분 단서, 핵심 정보 강조 | 가독성, 영역 구분 |
| 관련 정보의 통합성 | 지문·자료 참조, 관련 정보 근접 배치 | 문두·응답 동시 제시 |
| 응답 조작의 용이성 | 응답 방식 인지, 응답 결과 표시 | 조작 간결성, 조작 대상 크기 |

**분포**
- 학교급: 초 6, 중 6
- 교과: 국어·수학·과학·사회 각 3문항(교과마다 결함 2 + 결함 없음 1)
- 응답 형식: 선택형·단답형·끌어 놓기·선 잇기 각 3문항
- 준거별 결함 문항 2개는 응답 형식이 서로 다르다.

## 기존 평정 화면(`/index.html`)의 결함 스위치 재점검

기존 문항 내용(`Code.gs`)은 이 저장소에 없어 스위치 단위로만 새 준거에 대 보았다. 새 12문항은 아래 스위치를 쓰지 않는다.

| 기존 스위치 | 새 준거로 보면 |
|---|---|
| `smallChoices` | 가독성 — 결함 예시(작은 글자)와 같은 사례 |
| `noBorders` | 영역 구분 — 결함 예시(경계 없는 지문·선택지)와 같은 사례 |
| `stackpin`, `far` | 문두·응답 동시 제시 — 결함 예시(밀려나는 문두)와 같은 사례 |
| `decorSvg`(움직이는 별·캐릭터) | 장식 절제 — 결함 예시(움직이는 효과)와 같은 사례 |
| `decor: 'kid'`(말풍선 글) | 장식 절제와 정보 선별이 섞임 |
| `hideLines` | 응답 결과 표시와 수정 불가가 섞임 |
| `hierarchy: 'flat'` | 영역 구분·강조·가독성이 섞임 |
| `longPress` | 플랫폼 기능 수준 — 제외 대상 |
| `popup` | 지문·자료 참조 — 팝업이 문두까지 덮으면 문두·응답 지표와 섞임 |
