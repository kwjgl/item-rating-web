# 그림 작업 지시서 (Codex용)

평정용 디지털 평가 문항에 들어갈 그림 8장을 만들어 주세요.
이 폴더 `items/assets/`에 아래 **파일 이름 그대로** 올리면 문항 화면에 바로 반영됩니다.
지금은 같은 자리에 임시 그림(코드로 그린 SVG)이 들어가 있고, 파일이 없으면 계속 임시 그림이 보입니다.

## 어디에 올리나

- 저장소: `kwjgl/item-rating-web`
- 브랜치: `claude/wonderful-fermi-1an2he` (main에 합친 뒤라면 main)
- 폴더: `items/assets/`
- **이 폴더의 그림 파일만** 추가합니다. 다른 파일은 고치지 마세요.
  - 예외: PNG로 만들었다면 `items/items.js` 맨 위 `ART` 표에서 그 파일의 확장자만 `.png`로 바꿉니다.

## 모든 그림에 공통인 조건

1. **형식**
   - SVG를 권장합니다.
   - 하나의 파일 안에서 완결되어야 합니다. 바깥 그림·글꼴을 불러오면 안 되고, `<script>`와 `<text>` 요소도 넣지 마세요.
   - 파일 하나는 300KB 이하로 합니다.
   - PNG라면 아래 viewBox 크기의 2배 해상도로 만듭니다.
2. **크기와 배치:** 아래에 적은 **viewBox(가로×세로)를 정확히 지켜 주세요.**
   - 문항 화면이 그림 위에 기호(㉠~㉣)나 화살표를 덧그리기 때문입니다.
   - 위치가 어긋나면 기호가 엉뚱한 곳에 붙습니다.
3. **글자 금지:** 글자·숫자·기호·화살표·말풍선을 그림 안에 넣지 마세요. 이름표는 문항 화면이 따로 붙입니다.
4. **화풍**
   - 초·중학교 교과서 삽화처럼 단순하고 평평한 일러스트로 그립니다.
   - 같은 묶음(E11 3장, M12 3장)은 화풍·선 굵기·색감을 맞춰 주세요.
5. **배경:** 아이콘(E11)을 뺀 나머지는 배경을 불투명하게 채웁니다. 그림 아래의 임시 그림이 비쳐 보이면 안 됩니다.
6. **사진은 쓰지 않습니다.** 실제 사진을 바탕으로 하면 출처와 사용 허락이 필요하므로 일러스트로 그려 주세요.
7. **문항의 결함을 바꾸지 마세요.** 아래 '꼭 지킬 것'은 연구 설계 조건입니다. 더 보기 좋게 만들려고 바꾸면 평정 결과를 해석할 수 없게 됩니다.

## 1. `e03-strata.svg` — 지층 단면 (초등 과학, E03)

- **viewBox:** `0 0 900 600`
- **쓰임:** 학생이 "가장 먼저 쌓인 층"을 고르는 문항입니다.
  - 결함을 켠 판에서는 선택지가 '노란색 층·갈색 층·초록색 층·회색 층'처럼 **색 이름뿐**입니다.
  - 결함을 끈 판에서는 그림 오른쪽에 ㉠~㉣ 기호가 덧그려집니다.
- **그릴 것:** 수평으로 쌓인 지층 네 개를 옆에서 본 단면 그림. 맨 위(y 0~20)는 땅 위로 하늘색이나 옅은 배경입니다.
- **층 배치** (경계는 조금 물결쳐도 되지만 ±12px 안에서만):

| 층 | 위치 (y) | 색 |
|---|---|---|
| 1층(맨 위) | 20 ~ 150 | 노란색 |
| 2층 | 150 ~ 300 | 초록색 |
| 3층 | 300 ~ 450 | 회색 |
| 4층(맨 아래) | 450 ~ 600 | 갈색 |

- **꼭 지킬 것**
  - 네 층은 **무늬·질감·알갱이 크기가 모두 같고 색만 달라야** 합니다. 층마다 모래 무늬, 자갈, 화석처럼 다른 단서가 있으면 문항의 결함이 사라집니다.
  - 각 색은 누구나 '노란색·초록색·회색·갈색'으로 부를 수 있어야 합니다. 임시 그림의 색 `#E8C547`, `#6E9E4B`, `#9AA0A6`, `#8C6A43`을 참고하세요.
  - 오른쪽 띠(x 800~880)는 층 표면만 보이게 비워 둡니다. 결함을 끈 판에서 이 자리에 ㉠~㉣ 동그라미가 놓입니다(x 840, y 85·225·375·520).
  - 층이 기울거나 뒤집혀 보이면 안 됩니다. 문두에 "지층은 뒤집히지 않았습니다"라고 적혀 있습니다.

## 2. `m03-heat-room.svg` — 난로가 있는 방 (중등 과학, M03)

- **viewBox:** `0 0 480 330`
- **쓰임:** 전도·대류·복사를 나타내는 화살표 세 개(빨강·파랑·초록)를 문항 화면이 이 그림 위에 덧그립니다. **화살표는 그리지 마세요.**
- **그릴 것과 위치:**

| 요소 | 위치 |
|---|---|
| 방 | 바닥선 y = 300, 벽·바닥은 차분한 무채색 |
| 난로 몸체 | x 46~142, y 196~300. 앞쪽 창에 작은 불꽃 |
| 냄비 | 난로 위, x 56~132, y 166~196 |
| 냄비의 쇠 손잡이 | 냄비 오른쪽으로 길게, x 132~228, y 176~185 (전도 화살표가 이 위를 지납니다) |
| 사람 | 오른쪽에 서서 난로 쪽으로 손을 뻗은 사람. 머리 가운데 (410, 168), 뻗은 손 끝 (368, 239) |

- **꼭 지킬 것**
  - **비워 둘 자리:** 화살표가 지나는 곳은 무늬나 물건 없이 비워 둡니다.
    - 난로 위 공기 (x 90~320, y 30~150)
    - 손잡이 바로 위 (x 140~215, y 150~170)
    - 난로와 손 사이 (x 150~345, y 232~256)
  - **피할 색:** 빨강·파랑·초록이 두드러지는 색은 쓰지 마세요. 화살표 색과 헷갈립니다. 불꽃은 작은 주황색이면 됩니다.

## 올린 뒤 확인하는 법

GitHub Pages나 내려받은 저장소에서 아래 주소를 열어, 임시 그림 대신 새 그림이 보이는지 확인합니다.
기호·화살표가 그림의 제자리에 놓이는지도 함께 봅니다.

| 그림 | 확인 주소 |
|---|---|
| 지층 (기호 없는 판) | `items/index.html?set=E&item=3` |
| 지층 (기호 ㉠~㉣이 붙은 판) | `items/index.html?set=E&item=3&off=E03` |
| 방 (색 화살표만) | `items/index.html?set=M&item=3` |
| 방 (㉠㉡㉢ 기호 붙은 판) | `items/index.html?set=M&item=3&off=M03` |
| 동물 아이콘 | `items/index.html?set=E&item=11` |
| 하천 지형 | `items/index.html?set=M&item=12` |
