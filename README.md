# item-rating-web

디지털 평가 문항 평정 조사 도구 — 최종 준거(4준거 14지표), 평정용 24문항(초등 12 · 중등 12)

- `index.html` — 평정 조사 화면 (GitHub Pages). 앱스크립트 서버와 연결
- `Code.gs` — 앱스크립트 서버: 설정·결함 스위치(DEFECTS)·참여 코드·응답 저장
- `items/` — 문항 화면. 설계와 사용법은 [`items/DESIGN.md`](items/DESIGN.md)
  - `items/index.html` — 미리보기 (`?set=E|M&panel=1`)
  - `items/assets/` — 그림 파일. 작업 지시서: [`items/assets/README.md`](items/assets/README.md)
